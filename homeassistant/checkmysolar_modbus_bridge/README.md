# Check My Solar Modbus Bridge

Home Assistant app that polls **Fox ESS** inverters over Modbus TCP and sends live data to [Check My Solar](https://checkmy.solar) through a private Cloudflare tunnel. The bridge runs next to Home Assistant on Home Assistant OS (no separate Docker Compose stack).

**Modbus bridge docs:** [checkmy.solar/docs/using-the-app/modbus-bridge/](https://checkmy.solar/docs/using-the-app/modbus-bridge/)
