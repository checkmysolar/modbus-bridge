# Home Assistant apps

This repository publishes [Check My Solar Modbus Bridge](checkmysolar_modbus_bridge/README.md) as a Home Assistant Supervisor app.

Install by adding this Git repository under **Settings → Apps → App store → Repositories**, then install **Check My Solar Modbus Bridge**.

Full setup: [checkmysolar_modbus_bridge/DOCS.md](checkmysolar_modbus_bridge/DOCS.md).
